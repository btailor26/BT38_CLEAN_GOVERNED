# Amazon Developer / Appstore Logo

This folder also contains the BT38 Inventory artwork used for the Amazon Selling Partner Appstore / Amazon Developer submission.

## Important
- The BT38 Inventory Amazon Developer logo is publication/compliance branding, not a marketplace action icon.
- Do not replace it with the Amazon, eBay, Shopify or TikTok marketplace logos.
- Do not repurpose or modify it as part of Warehouse marketplace-control UI work.
- The public BT38 landing page should use the same BT38 Inventory identity when aligning the website with the Amazon Appstore submission.
- Keep Amazon-required resized variants derived from the same master artwork so the website and Appstore branding remain visually consistent.

Purpose: prevent the Amazon Developer/Appstore branding asset from being confused with the marketplace logos used by the Warehouse page.
